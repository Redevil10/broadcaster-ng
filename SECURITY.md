# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Redevil10/broadcaster-ng/security/advisories/new)
rather than in a public issue. You should get a reply within a week.

## Supported versions

Security fixes go into the latest release of `broadcaster-ng`. The original
`encode/broadcaster` package is archived and no longer receives fixes.
